

# Exercícios Função Lambda Map, Filter e Fold


## Filter == Filtrar:

1. Dada uma lista de formas, devolve todos os retângulos da lista.
Filtrar 2. Dada uma lista de formas, devolve todos os triângulos da lista.
3. Dada uma lista de formas, devolve todos os retângulos que tem base maior que 40.
4. Dada uma lista de formas e um número, devolve todas as estrelas com lado maior que este número.


### Map == Mapear:
5. Dada uma lista de formas, devolve uma lista com as cores das formas da lista.
6. Dada uma lista de formas, devolve os perímetros das formas da lista.
7. Dada uma lista de formas, muda a cor de todas as formas para “orange”.

### Fold == Juntar:

8. Dada uma lista de formas e uma cor, muda a cor de todas as formas para esta cor.
9. Dada uma lista de imagens de formas, devolve uma imagem com todas as formas da lista, lado a lado.
10. Dada uma lista de perímetros de formas, devolve a soma dos perímetros da lista.
11. Dada uma lista de formas, devolve uma imagem com todas as formas da lista, lado a lado.

### Combinação:

12. Dada uma lista de formas, devolve a soma das bases dos retângulos da lista.
13. Dada uma lista de formas e uma cor, gera uma imagem com as formas desta cor.
14. Dada uma lista de formas, devolve uma imagem com os identificadores das formas, cada um escrito na cor da respectiva forma
